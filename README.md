# Sleep Analytics

Этот проект собирает данные о вашем сне и активности за компьютером. Для анализа используется простая модель машинного обучения.

## Основные возможности
- Отслеживание активности мыши и клавиатуры
- Определение сна при отсутствии активности 30 минут
- Сохранение статистики в `sleep_data.json`
- Умный будильник с окном мягкого пробуждения
- Веб‑дашборд на Flask с графиками и рекомендациями
- Экранное время за день
- Получение сигналов сна/пробуждения от телефона (`/api/signal`)
- Получение текущей погоды через `/api/weather`
- Прогноз качества сна через `/api/predict-quality`
- Современный 3D-дизайн дашборда

Для запуска используйте:
```bash
python sleep_web_server.py
```
